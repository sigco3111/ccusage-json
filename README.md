# 클로드코드 사용량 대시보드 (ClaudeCode Usage Dashboard)

`ccusage` JSON 파일을 업로드하여 AI 모델 사용량 및 비용 데이터를 시각화하는 웹 애플리케이션입니다. 일일 동향, 모델별 비용 분포 등 다양한 관점에서 데이터를 분석할 수 있는 인터랙티브 대시보드를 제공합니다.

 
*(스크린샷 이미지는 예시입니다)*

---

## ✨ 주요 기능

- **📁 파일 업로드**: 드래그 앤 드롭 또는 파일 선택기를 통해 간편하게 `ccusage` JSON 파일을 업로드할 수 있습니다.
- **📊 종합 통계**: 총비용, 총 토큰, 입/출력 토큰 등 핵심 지표를 한눈에 파악할 수 있는 통계 카드를 제공합니다.
- **📈 일일 사용량 추이**: 시간 경과에 따른 비용 및 토큰 사용량 변화를 시각적으로 보여주는 라인 차트입니다.
- **🥧 모델별 비용 분포**: 사용된 AI 모델들의 비용 점유율을 보여주는 파이 차트입니다.
  - **🖱️ 데이터 드릴다운**: 파이 차트에서 특정 모델을 클릭하면, 전체 대시보드가 해당 모델의 데이터만 필터링하여 보여줍니다. 필터를 해제하여 다시 전체 데이터를 볼 수 있습니다.
- **📋 상세 데이터 테이블**: 일일 사용 내역을 상세하게 보여주는 테이블입니다.
  - **↕️ 데이터 정렬**: 날짜, 토큰, 비용 등 원하는 기준으로 데이터를 오름차순 또는 내림차순으로 정렬할 수 있습니다.
- **📱 반응형 디자인**: 데스크톱, 태블릿, 모바일 등 다양한 기기에서 최적화된 화면을 제공합니다.

---

## 🚀 사용 방법

1.  웹 애플리케이션을 엽니다.
2.  '클릭하여 업로드' 버튼을 누르거나 `ccusage` JSON 파일을 지정된 영역으로 드래그 앤 드롭합니다.
3.  파일이 성공적으로 처리되면, 데이터가 시각화된 대시보드가 나타납니다.
4.  차트와 테이블의 인터랙티브 기능을 활용하여 데이터를 탐색하고 분석합니다.
5.  다른 파일을 분석하려면 '새 파일 업로드' 버튼을 클릭하세요.

## 🛠️ 기술 스택

- **프레임워크**: React
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **차트 라이브러리**: Recharts
- **빌드 도구**: Vite (esbuild를 통한 빠른 개발 서버)

## 🔮 향후 개선 계획

- **기간 필터링**: 사용자가 원하는 날짜 범위를 직접 선택하여 데이터를 필터링하는 기능 추가
- **데이터 비교**: 두 개의 다른 `ccusage` 파일을 업로드하여 데이터를 나란히 비교 분석하는 기능 추가
- **데이터 내보내기**: 필터링 및 정렬된 데이터를 CSV 파일로 다운로드하는 기능 추가
- **성능 최적화**: 대용량 데이터 처리를 위한 테이블 가상화(Virtualization) 및 차트 렌더링 최적화
